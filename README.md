# ANIWAVE - 클라우드 기반 애니메이션 & 굿즈 판매 사이트

ANIWAVE는 클라우드 기반 오픈 API를 활용한 반응형 애니메이션 및 굿즈 판매 사이트입니다. 이 프로젝트는 다양한 기술을 사용하여 애니메이션 및 굿즈 관련 상품을 판매하고, 사용자에게 직관적이고 효율적인 쇼핑 경험을 제공합니다.

## 프로젝트 개요

- **프로젝트 이름**: ANIWAVE
- **기간**: 2024-09-19 ~ 2024-10-30
- **팀장**: 이효민
- **팀원**:
  - 김정
  - 김채원
  - 최보람
  - 최철순

## 주요 기능

- **회원 관리**: 로그인, 회원가입 (JWT 사용), ID/PW 찾기 기능 구현
- **애니메이션 및 굿즈 판매**: 애니메이션 리스트 및 필터링, 검색, 디테일 페이지 제공
- **마이페이지**: 사용자 개인 정보, 주문 내역 확인, 장바구니 기능
- **결제 시스템**: Toss Payments API를 이용한 결제 기능 구현
- **관리자 페이지**: 관리자 주문 관리 및 이벤트 관리 기능
- **커뮤니티 기능**: 공지사항, 문의사항, 댓글 및 대댓글 기능
